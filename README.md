# Analise-Comercial-Performance-Vendas-Automotivas-BI
Dashboard interativo desenvolvido para análise do desempenho comercial de vendas de veículos, explorando indicadores como faturamento, volume de vendas, ticket médio, preço médio, desempenho de vendedores e participação das marcas.
